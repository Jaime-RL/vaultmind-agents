# ERA5

Reanálisis climático global producido por el ECMWF para el servicio de cambio climático de Copernicus. Ofrece datos horarios de muchas variables atmosféricas desde 1940 con una resolución de unos 31 km.

Se descarga desde el [[Copernicus Climate Data Store]] y también se puede consultar de forma indirecta a través de [[Open-Meteo]].

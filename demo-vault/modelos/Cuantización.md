# Cuantización

Reducir la precisión de los pesos de un modelo (por ejemplo de 16 bits a 8 o 4 bits) para que ocupe menos memoria y se ejecute más rápido, a cambio de una pequeña pérdida de calidad.

Muy útil para desplegar un [[SLM]] en hardware modesto. Relacionado con [[Destilación de conocimiento]] como forma de abaratar la inferencia.
